Política de privacidad

Última actualización: 1 de noviembre de 2026.

Fenix Dashboard es una aplicación personal de un solo usuario: su desarrollador es también su único usuario.

Qué datos usa

Con autorización explícita del usuario, la aplicación lee en modo solo lectura datos de la Google Health API (sueño, frecuencia cardíaca, variabilidad de la frecuencia cardíaca, frecuencia respiratoria, saturación de oxígeno y temperatura), además de datos de Garmin Connect y del Logbook de Concept2.

Para qué

Únicamente para calcular y mostrarle al propio usuario métricas de recuperación, sueño y entrenamiento.

Dónde se guardan

En un servidor personal del usuario, accesible solo desde su red privada. Los tokens de acceso se guardan localmente y nunca se publican.

Con quién se comparten

Con nadie. No se venden, no se transfieren a terceros, no se usan para publicidad ni para entrenar modelos. El uso de datos recibidos de las APIs de Google cumple la Google API Services User Data Policy, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El usuario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions y borrar los datos guardados en su servidor.
